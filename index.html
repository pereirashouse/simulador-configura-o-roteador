Simulador educacional de roteador

Este projeto simula uma interface de configuração de roteador. As alterações são fictícias e executadas no navegador.

Objetivo

Compreender SSID, canais, largura de banda, segurança, QoS e ferramentas básicas de administração de rede.

Para quem

Estudantes dos anos finais do Ensino Fundamental e do Ensino Médio (eixo Mundo Digital da BNCC Computação), cursos técnicos e oficinas de introdução a redes. Não precisa de conhecimento prévio além de saber o que é uma rede Wi-Fi.

Como usar

  1. Leia o desafio no quadro Desafios.
  2. Navegue pelo menu do roteador, altere as configurações e clique em Salvar no painel.
  3. Clique em Verificar no desafio. O simulador confere o que foi salvo e explica o que está certo ou errado.
  4. Use a dica só se precisar.

Para o professor

São seis desafios em ordem de dificuldade, pensados para uma aula de 50 minutos (cerca de 5 a 8 minutos por desafio, mais a discussão final). O progresso fica salvo só neste navegador. Para recomeçar com uma turma nova, use Recomeçar tudo no fim do quadro de desafios. Os critérios de cada desafio estão descritos no README do projeto.
