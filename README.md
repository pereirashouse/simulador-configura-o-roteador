# Simulador de configuração de roteador

Simulador educacional de um painel de roteador Wi-Fi residencial, usado em oficina da Licenciatura em Computação para praticar conceitos de rede sem fio (SSID, canal, largura de canal e QoS).

> **Simulador educacional — não é um roteador real.** As configurações são fictícias e executadas somente no navegador. Nada é enviado a nenhum equipamento.

**Demonstração:** https://pereirashouse.github.io/simulador-configura-o-roteador/

## Como executar

Abra `index.html` em qualquer navegador. Não há dependências nem servidor.

## Como funciona

- Menu lateral com os painéis Status, Wireless 2.4 GHz, Wireless 5 GHz, QoS e Ferramentas do Sistema.
- Ao clicar em **Salvar**, o simulador confere os campos do painel (SSID preenchido e com até 32 caracteres, banda de QoS só com números) e mostra uma mensagem de erro ou de configuração aplicada no simulador.
